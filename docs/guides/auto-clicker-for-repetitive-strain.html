Using an auto clicker to reduce clicking strain

If clicking hurts, from RSI, a tendon problem or limited hand mobility, an autoclicker can take over the repetitive part. You press one key; it does the hundreds of clicks.

This is a tool for repetitive clicking, not medical advice and not a replacement for accessibility software such as Windows' own Mouse Keys, dwell clicking or speech control. If clicking hurts, talk to a doctor or occupational therapist too.

One key to start and stop

Under App → Hotkeys..., set a toggle key: the same key starts and stops. Pick one that is easy to reach for you. Hotkeys work while other windows are in front.

Long presses without holding

Under Click Settings, Action: Hold presses the mouse button for a set time (up to 60 seconds) and releases it, for apps that need a long press or a drag-like hold. The button is always released, whatever stops the run.

Repeat a key instead of clicking

Action: Key presses a key such as F5, Space or Ctrl+R at your interval, into whichever window is in front.

Click where the cursor is

With Target: Cursor, clicks go wherever you leave the mouse, so you only need to move it, not click.

Save your setups

Save each setup as a profile, then start it from a desktop shortcut, a macro pad or Task Scheduler: WindowsAutoclicker.exe --profile Reading --start.
