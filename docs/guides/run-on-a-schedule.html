Run the autoclicker on a schedule

Later today: Start at

  1. Open Timing and type a 24-hour time in Start at, such as 09:30.
  2. Press Start. The status bar counts down: Starting at 09:30 (in 1:59:30).
  3. Stop, the tray's Stop or the toggle key cancel it. The global Stop and Emergency keys are claimed only for the last minute, so Esc keeps working in other apps while you wait.

The same works from the command line: WindowsAutoclicker.exe --profile Work --start-at 09:30 --start.

Every day: Task Scheduler

  1. Save your setup as a profile (Save Profile), and give it a click or time limit so an unattended run ends on its own.
  2. Open Task Scheduler and choose Create Basic Task. Pick a trigger such as Daily or When I log on.
  3. Action: Start a program. Program: the full path to WindowsAutoclicker.exe. Arguments: --profile Work --start --minimized, or --profile Work --headless to run without a window and exit when done.
  4. In the task's properties keep Run only when user is logged on.
Windows only accepts mouse and keyboard input on a signed-in, unlocked desktop. A task that runs at the lock screen, or for another user, clicks nothing.

A headless run exits with a code that says how it ended: 0 done or stopped, 2 bad options, 3 emergency stop, 4 failsafe or speed guard, 5 error, 6 already running.
