Windows SmartScreen and antivirus warnings

"Windows protected your PC"

SmartScreen warns about programs that aren't code-signed and that it hasn't seen often. The exe isn't signed yet, so you may see it. If you downloaded it from the official release page, choose More info, then Run anyway. To be sure first, verify the download.

Antivirus flags or deletes it

Some engines flag tools like this even when they are clean. Two things trigger it: the exe is a PyInstaller bundle (a Python app packed into one file), and it moves the mouse, which heuristics find suspicious.

  1. Verify the file: checksum and build provenance.
  2. If it matches, restore it from quarantine and add an exclusion for it.
  3. Please report the false positive to your vendor. For Microsoft Defender, submit the file as "incorrectly detected". Each report helps the next person.
Prefer not to run an exe at all? You can run it from source with Python 3.10 or newer.
