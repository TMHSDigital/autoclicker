Windows Autoclicker

Pick a spot, set the pace, press F6.

A fast, careful autoclicker for Windows, with safety stops that are on by default.

Everything a clicker should do

From one spot clicked every second to a multi-step routine run from a shortcut.

Pick and click

Type X and Y, or press Pick for a live readout on any monitor. Or click wherever the cursor is, and spread clicks up to 50 px around the spot.

Record a routine

Press Record and click through it once. Every click becomes a step with its own wait, ready to replay as often as you like.

Click a button wherever it appears

Capture a button once. Each click goes wherever that image is on screen. The run waits while it isn't there, or stops once it has been gone for as long as you choose.

Precise timing

Intervals from 0 ms to 60 s, random variation, and bursts of quick clicks between waits. Start or stop at a time of day.

Hold and key actions

Hold a mouse button for a set time, or press a key such as F5 or Ctrl+R instead of clicking.

Profiles and command line

Save everything by name and share it as a file. Start a profile from a shortcut or Task Scheduler, or run headless.

Stops when you need it to

An autoclicker that won't stop is worse than none, so every run has several ways out.

Corner failsafe
Slam the mouse into a corner of any monitor to abort. Corners between screens are ignored.
Emergency stop
Esc halts immediately from anywhere. Every hotkey can be rebound.
Limits and speed guard
Stop after N clicks or N minutes, and stop automatically if clicks run faster than your speed limit.
Pause when the window isn't in front
Clicking pauses whenever the target window isn't in front, and resumes when it is.
Only while a pixel matches
Sample a color, and clicking waits or stops as soon as that spot on screen changes.
Start countdown
The Start button waits 3 seconds so you can let go of the mouse. Any stop key cancels it.

Up and running in a minute

No setup, nothing to install.

  1. Download the single WindowsAutoclicker.exe.
  2. Run it. Choose More info, Run anyway if SmartScreen asks.
  3. Pick a target with Pick, or use the cursor.
  4. Press F6. F7 or Esc stops it.

Prefer a package manager? With Scoop:

scoop bucket add tmhs https://github.com/TMHSDigital/autoclicker
scoop install tmhs/windows-autoclicker

Want it on a USB stick? The portable zip keeps settings and logs in a data folder next to the exe.

From a shortcut or a script:

WindowsAutoclicker.exe --profile Work --start --minimized
WindowsAutoclicker.exe --at 800,600 --interval 250ms --clicks 100 --start
WindowsAutoclicker.exe --profile Work --start-at 09:30 --stop-at 17:00 --start

Who it's for

Anyone tired of clicking the same thing over and over.

If clicking hurts, press one key instead of clicking hundreds of times. Long holds and key repeat help too. It doesn't replace accessibility software or medical advice.

For testing and QA, repeat a click path to reproduce a bug or soak-test a button. Headless runs exit with a code that says how they ended, or print it as JSON.

For repetitive work and games, click through the same form or dialog step after step, or play idle games where the rules allow it.

Questions

The short answers. The README has the details.

Is it safe to download?

Every release is built by GitHub Actions from the public repository and ships with a SHA-256 checksum and a build provenance attestation, so you can confirm the file came from that build. How to verify a download.

Why does Windows SmartScreen warn about it?

The executable isn't code-signed yet, and SmartScreen warns about unsigned programs it hasn't seen often. Choose More info, then Run anyway, or verify the checksum first.

My antivirus flags it. Is something wrong?

Probably not. Unsigned single-file Python apps, especially ones that move the mouse, are a common false positive. Check that the file's SHA-256 matches the release's .sha256 file (PowerShell: Get-FileHash) and, if you like, look the hash up on VirusTotal. If it matches, restore it, and please report the false positive to your antivirus vendor. Step by step.

Does it send any data?

No. It makes no network requests unless you turn on the daily update check, which only reads the public latest-release page on GitHub.

Will it work in my game or app?

It works with most Windows programs. Apps running as administrator need the autoclicker to run as administrator too, and some games ignore synthetic input. Only automate software whose terms allow it.
